# Kotlin Diary App

Jetpack Composeを使った日記アプリ - モダンAndroid開発の学習プロジェクト

## 概要
Jetpack Compose、Room Database、ViewModel、Hiltなどのモダンなアーキテクチャを学習するためのプロジェクトです。

## 機能
- [ ] 日記の作成・編集・削除
- [ ] 日付ごとの一覧表示
- [ ] 気分選択（絵文字）
- [ ] 検索機能
- [ ] カレンダービュー

## 技術スタック
- Jetpack Compose
- Room Database
- ViewModel + StateFlow
- Hilt (Dependency Injection)
- Navigation Compose
- Coroutines + Flow
- Material Design 3

## 学習目標
- Jetpack Compose UI
- MVVM アーキテクチャ
- Room Database
- Coroutines による非同期処理
- Dependency Injection
- Navigation Component

## 開発環境
- Android Studio
- Minimum SDK: API 24
- Target SDK: API 34

## 開発ロードマップ
- [ ] Week 1: セットアップ、Compose基礎、Room DB
- [ ] Week 2: 一覧・詳細画面、ViewModel
- [ ] Week 3: Hilt、Repository、Coroutines
- [ ] Week 4: 追加機能、UI改善
